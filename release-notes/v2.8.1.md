# Logchef v2.8.1

Four fixes found while recording the v2.8.0 launch videos. No migrations: upgrade in place from v2.8.0.

## Fixed

- **Email with a display-name From address.** A From setting such as `Logchef <logchef@example.com>` went into SMTP `MAIL FROM` whole, so strict servers refused every alert, report and test email. The envelope now gets the bare address and the From header keeps the name. The From and Reply-To settings now refuse a value that is not an email address.
- **Field sidebar after an aggregation.** With `level=error | count() by service` in the Explorer, every field in the sidebar failed with HTTP 500. Values are now counted over the filter in front of the pipe, on ClickHouse, VictoriaLogs and Loki. A malformed field-value filter answers 400.
- **Expanded row controls.** A long column pushed the Fields/JSON switch and **Show Context** off screen to the right of the table. They now stay within the visible width, down to phone width, and the table header stays pinned while rows scroll.
- **Dashboard table times.** A VictoriaLogs table printed raw UTC ISO times while a Loki table beside it printed local times with nanosecond digits. Table panels now show time columns in one format and in the viewer's zone on every backend.

## Upgrading

Replace the binary or image with v2.8.1 and restart. Coming from v2.7 or earlier, read the [v2.8.0 upgrade notes](https://github.com/mr-karan/logchef/releases/tag/v2.8.0) first: that upgrade needs downtime and a database backup.

```bash
docker pull ghcr.io/mr-karan/logchef:v2.8.1
```
